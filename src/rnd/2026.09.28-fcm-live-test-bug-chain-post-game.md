- **Zero rolling deposits from a four-seat crew.** Everything above was reconstructed from commits and a memento, which is testimony tier 3–4.

## 6. Lessons for the failure-mode catalog

- **`mock-shape-from-memory`**: the test fixture encodes the author's belief about the wire format. *Symptom*: green unit tests and a red first live call. *Guard*: fixtures captured from the real endpoint, plus one contract test per consumed endpoint.
- **`log-says-done-os-says-no`**: the app logs success for a call the OS silently no-ops (a denied permission). *Guard*: log the permission state alongside the action.
