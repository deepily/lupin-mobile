## 0. The ask, restated

Lupin's browser client is enormous; mobile cannot show everything the same way. Three concrete pains on the phone:

1. **Focus rail is a mile long and every badge is the same letter.** The rail lists *every sender ever* and renders a sender-id initial.
2. **Tool-call chatter** (`Done: mcp…`, `Done: Bash`, `Done: ToolSearch`) lands as one bubble per call (the browser collapses them into one DOM node) and gets spoken.
3. No user-editable way to say "never show / never speak lines like *this*".

## 3. Workstream B — Notification stop-list (hide + mute)

**Model**: `NotificationStopList` (`lib/services/notification_filter/`) — ordered list of `StopPattern { String pattern; bool enabled; }`, persisted as JSON in `SharedPreferences` key `notif_filter.stop_list`. **Seeds** (enabled): `Done: mcp`, `Done: Bash`, `Done: ToolSearch`, `Done: Read`, `Done: Edit`, `Done: Write`, `Done: Grep`, `Done: Glob`. Match = **case-insensitive prefix** on `message` (trimmed); `matches( NotificationItem ) → bool`.

**Application (three seams, one predicate)**:
- Focus bloc ingest: matched item → stored with `hidden=true` (card retained, not rendered, not counted unread) **and not enqueued to TTS** (`enqueueAlways` skipped).
- Inbox/conversation list: hidden items filtered from the rendered list; "show N hidden" reveal chip.
- `TtsOrchestrator.enqueue*`: predicate checked first (belt + suspenders for any other dispatcher).

**UI**: `NotificationFilterSettingsScreen` — checklist (checked = hide + mute), swipe-to-delete, "+ add pattern" field, "reset to defaults". Linked from Settings next to the audio screen.

**Tests**: unit (matcher, persistence round-trip, seeds), bloc (hidden not rendered/not spoken/not unread), widget (checklist toggles persist). 100%.

## 4. Workstream C — Collapse by `progressGroupId` (default on)

Consecutive items in a sender window sharing `progressGroupId` render as **one expandable row**: latest message as the summary line, `×N` count badge, tap to expand. Pure render grouping in the focus pane + conversation screen; no state deletion, no TTS change (stop-list owns TTS). Settings toggle `notif_filter.collapse_groups` (default true).

**Tests**: widget (N grouped items → 1 row + count; expand shows all; toggle off → N rows). 100%.
