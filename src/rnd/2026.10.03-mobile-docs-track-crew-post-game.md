## 2. What went right (keep)

- **The comments-stripped comparison on every commit.** It proves "comments only" mechanically, so about 4,900 doc comments landed with no behaviour change to argue about. Receipt: suite NO_NEW_FAILURE at `c45b9f8` and at `d0c5da8`.
- **The stop rule for a test that asserts comment text.** Both workers stopped, restored the file and asked, instead of editing the test (`43b5c8c`, `5c7b75a`). The cost was two files left for a day, and Rick's ruling settled both.
- **A "Removed, not history" list in every commit message.** A reader can audit what a rewrite dropped without diffing 20 directories.
- **One full suite per merged batch, not per directory.** The per-directory suite was the bottleneck; the batch gate found the same answer once.
- **Measuring before claiming.** Clayton measured `--fatal-infos` on 16 directories and reported 8 pass, 8 do not; that measurement is what exposed the gate design problem the same evening.
- **Negative controls in review.** Pocholo broke the code on purpose and showed the tests go red (row `4c62c7b9`), and did the same for the rebuilt gate (`28b7ea0`).
- **Bugs reported, not fixed in passing.** Krishna noted the retired submit path and left it; it became bug `bdd60a1b` and a separate reviewed commit.

## 3. What went wrong (fix)

1. **The gate script lived in the manager's scratchpad, so a re-spin took the ability to merge with it.** Finished work from two seats waited about five and a half hours, and only Rick running the script by hand ended it. The script is still not in the repo (`git ls-files | grep batch.sh` returns nothing, run 2026-10-03).
2. **The hook and CI step were built on a pass condition nobody had measured against the target directories.** John had recorded on 09-30 that `--fatal-infos` needs zero infos of any kind; on 10-01 the gate was built on it anyway and could cover 12 of 25 directories. It was rebuilt the next day (`28b7ea0`).
3. **A dead module was swept.** `lib/features/voice` did not compile and was unreferenced; 96 doc comments were written for it on 10-01 and deleted with it on 10-02. Nobody checked that a directory compiles and is used before sweeping it.
4. **The manager accepted a demonstration from a transcript.** The run used a clean directory and bypassed the installed hook; the row stayed open for two days until Pocholo reran it on 2026-10-03.
5. **No worker was asked to deposit lessons as they went.** The briefs did not say so, both sweep workers were reaped the same night, and what they learned survives only as memento procedure notes.
6. **Volume outran verification.** Two seats with forks wrote thousands of doc comments in about an hour, and the only check of whether those comments are true is still blocked.
7. **A relayed ruling could not be recorded**, so a day's decisions sat unwritten until Rick confirmed first-hand.
8. **Five rows minted in error**, each needing a drop.
9. **The plan manifest is stale.** `src/docs/plan-stubs/mobile-docs-track.stubs.json` still says `--fatal-infos` in four places after the gate changed (`grep -c`, run 2026-10-03).

## 6. Lessons for the failure-mode catalog

- **Gate held hostage by a re-spin.** Trigger: the only copy of a merge gate is in a session scratchpad. Symptom: finished work cannot land after the manager clears context. Guard: R1.
- **Gate built on an unmeasured predicate.** Trigger: a tool's pass condition is assumed to hold for the set it will guard. Symptom: the gate covers half the set and is rebuilt. Guard: R2.
