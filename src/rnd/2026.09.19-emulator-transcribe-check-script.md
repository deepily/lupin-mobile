## Then, on the emulator

1. **Sign in.** Server picker on the sign-in screen → **LAN DEV**.
2. **Quick Ask** screen.
3. Set the send-mode control to **Review first** — i.e. *Send immediately* **OFF**.
   This matters: *Send immediately* takes a different branch in the bloc
   (`quick_ask_bloc.dart:212`), one request with a two-line reply. **Review first** is the
   branch that calls `AsrService` on its own, which is the one under test.
4. **Press and hold the mic**, say anything — *"what's the sum of two plus two"* is the
   usual — and release.
5. The transcript appears in the review box. You do **not** need to send it. The call
   already happened.

## ⚠️ One thing you will see that you should ignore for now

That same tail prints your **bearer token in full**, and the sign-in response prints
**both** tokens in plaintext. I filed it tonight as `a7de7d69` (P2) — Dio's
`LogInterceptor` at `lib/services/network/http_service.dart:55` defaults
`requestHeader: true` and has no `kDebugMode` guard, so a release APK does it too.

It does not affect this check: the line you are pasting comes from a **different**
interceptor (line 63), which prints only method and URI. But do not paste the raw tail
into a channel that keeps history — just the one `Request: POST` line.
