# Lupin Voice-Persona Validation Runbook — Three-Domain Split

This document delivers three production artifacts for splitting the Lupin `vp1`–`vp7` runbook into mutually exclusive execution domains: **(1)** a Claude Code prompt that produces the split, **(2)** a complete Patrol bootstrap + automated test bundle for `vp1`–`vp4` and the infrastructure portions of `vp6`/`vp7`, and **(3)** a single-file Python CLI for the residual human-perception gates (`vp5`, `vp6`-perceptual, `vp7`-audible). All three are designed to compose into a single milestone close-out artifact.

A note on the architectural premise that motivates this decomposition: Flutter rasterises its widget tree into a single `SurfaceView`/`FlutterView` canvas, which means the Android Accessibility tree exposes essentially nothing usable to `uiautomator` or Espresso. Patrol bridges this gap by injecting a Dart-side test driver (via `integration_test` + a `PatrolJUnitRunner` instrumentation harness) that exposes Flutter's element tree to the test process while still allowing native-level affordances (system dialogs, dark mode toggle, `pressHome`, etc.) through `$.native`. Anything Patrol cannot mechanically observe — TTS timbre, perceived contrast, audible engine identity — is delegated to `deliverable 3`.

## Deliverable 1 — Claude Code Prompt: Runbook Splitter

Save the following as `prompts/split_runbook.md` and invoke it with `claude --file prompts/split_runbook.md` (or paste it directly into a Claude Code session). The prompt is fully self-contained: it specifies input/output paths, gate-to-domain mapping rules, formatting conventions, and quality acceptance criteria.

````markdown
# Task: Split Lupin VP1–VP7 Runbook into Three Domain Files

You are a release-engineering automation agent. You will read one consolidated
voice-persona validation runbook and emit THREE strictly-scoped child files
that partition every gate by execution modality. Do not invent gates that do
not appear in the source; do not silently elide gates that do.

## Input

- Path: `docs/runbooks/voice_persona_validation.md`
- Format: Markdown. Gates are headed `## vpN — <title>` for N ∈ {1..7}.
- Treat the source as authoritative; copy gate IDs and acceptance criteria
  verbatim into the output files.

## Outputs (create or overwrite, in this exact order)

1. `docs/runbooks/voice_persona/automated_patrol.md`
   — gates that can be mechanically asserted by Patrol + ADB logcat.
2. `docs/runbooks/voice_persona/human_perception.md`
   — gates that require a human ear or eye.
3. `docs/runbooks/voice_persona/metadata_signoff.md`
   — the gate sign-off recording protocol consumed by
     `tools/qa/human_signoff.py` (Deliverable 3).

## Mapping Rules (apply in order; each gate goes to exactly one bucket)

| Gate           | Destination file        | Rationale                                                |
|----------------|-------------------------|----------------------------------------------------------|
| vp1            | automated_patrol.md     | Widget identity (badge vs CircleAvatar) + tooltip text   |
| vp2            | automated_patrol.md     | Widget size, text, colour equality across screens        |
| vp3            | automated_patrol.md     | Widget size + sibling layout in `_NotificationItemCard`  |
| vp4            | automated_patrol.md     | Conditional widget overlay; skip if no borrowed sender   |
| vp5            | human_perception.md     | Perceptual contrast in light + dark mode                 |
| vp6 (infra)    | automated_patrol.md     | Logcat WS-envelope `voice_id` ∈ persona table; not Sam   |
| vp6 (timbre)   | human_perception.md     | Audible match to Adam/Bella/Domi/Antoni/Rachel/Arnold    |
| vp7 (infra)    | automated_patrol.md     | Logcat shows `flutter_tts` engine path; 5-min TS window  |
| vp7 (audible)  | human_perception.md     | Listener confirms robotic on-device cadence              |

For `vp6` and `vp7`, split the original gate body into two subsections in the
two destination files; preserve the original `vpN` label and append
`-infra` or `-perceptual`/`-audible` as appropriate.

## File 1 — `automated_patrol.md` content rules

- Top of file: H1 `# Automated Patrol Gates — vp1, vp2, vp3, vp4, vp6-infra, vp7-infra`.
- Include the exact `curl` prerequisite (verbatim from source) under
  `## Prerequisite — backend status probe`.
- For each gate produce:
  - `### vpN — <title>`
  - `**Acceptance**` (verbatim from source)
  - `**Patrol entrypoint**` — file path under `integration_test/` that
    contains the corresponding `patrolTest`. Use these exact names:
    - vp1 → `integration_test/vp1_inbox_badge_test.dart`
    - vp2 → `integration_test/vp2_appbar_badge_test.dart`
    - vp3 → `integration_test/vp3_conv_by_date_badge_test.dart`
    - vp4 → `integration_test/vp4_borrowed_dashed_test.dart`
    - vp6-infra → `integration_test/vp6_voice_id_logcat_test.dart`
    - vp7-infra → `integration_test/vp7_quota_fallback_logcat_test.dart`
  - `**Logcat assertion**` — exact regex grep pattern against the WS envelope
    (`voice_id="[a-zA-Z0-9]{20}"`) or engine tag (`I/flutter_tts:` for vp7).
  - `**CLI invocation**` — copy-pasteable `patrol test --target … --tags …`.

## File 2 — `human_perception.md` content rules

- Top of file: H1 `# Human-Perception Gates — vp5, vp6-perceptual, vp7-audible`.
- Embed the seven-row ElevenLabs persona table verbatim from source.
- For each gate produce:
  - `### vpN-<suffix> — <title>`
  - `**Acceptance**` (verbatim)
  - `**Operator action**` — one-sentence instruction (e.g. "Listen to s2,
    confirm timbre matches the persona allocated by `/voice-persona/status`").
  - `**Capture format**` — `THUMB={UP|DOWN}; OBSERVATION=<free text>; TS=<ISO-8601>`.
- End the file with a `## Sign-off` section that points to
  `tools/qa/human_signoff.py` and explains it must be the last step before
  milestone close.

## File 3 — `metadata_signoff.md` content rules

- One H1, then a fenced shell block showing the exact invocation:
  ```bash
  python tools/qa/human_signoff.py \
      --runbook docs/runbooks/voice_persona/human_perception.md \
      --output  docs/runbooks/voice_persona/signoff_$(date +%Y%m%d_%H%M).md
  ```
- Document the metadata fields the script captures (device model via
  `adb shell getprop ro.product.model`, Android release via
  `adb shell getprop ro.build.version.release`, APK commit via
  `git rev-parse --short HEAD`, ISO-8601 timestamp, operator name from `$USER`).

## Quality criteria (the agent MUST self-check before declaring done)

1. Every gate ID `vp1..vp7` appears in exactly one file (vp6/vp7 may appear
   in two files but with the `-infra` / `-perceptual|audible` suffixes).
2. No file contains the literal token `TODO`, `…`, `<implement>`, or
   placeholder ellipsis.
3. The `curl` prerequisite line is byte-identical to the source.
4. Persona voice_id table preserves all seven rows with ID strings unchanged.
5. CLI invocations in `automated_patrol.md` are copy-pasteable shell.
6. Run `markdownlint --disable MD013 MD033` on each output; fix all errors.
7. After writing, print a short JSON manifest to stdout of the form
   `{"automated":<path>,"human":<path>,"signoff":<path>,"gate_count":7}`.

Do not ask clarifying questions. If the source is missing a field, fail loudly
by emitting `ERROR: missing field <name>` to stderr and exit non-zero.
````

### 2.3 Native test runner — `android/app/src/androidTest/java/com/google/lupin/app/MainActivityTest.kt`

```kotlin
package com.google.lupin.app

import androidx.test.platform.app.InstrumentationRegistry
import org.junit.runner.RunWith
import org.junit.runners.Parameterized
import pl.leancode.patrol.PatrolJUnitRunner

@RunWith(Parameterized::class)
class MainActivityTest(@Suppress("UNUSED_PARAMETER") dartTestName: String) {

    companion object {
        @JvmStatic
        @Parameterized.Parameters(name = "{0}")
        fun testCases(): Array<Any> {
            val instrumentation = InstrumentationRegistry.getInstrumentation()
                    as PatrolJUnitRunner
            instrumentation.setUp(MainActivity::class.java)
            instrumentation.waitForPatrolAppService()
            return instrumentation.listDartTests()
        }
    }

    @org.junit.Test
    fun runDartTest() {
        val instrumentation = InstrumentationRegistry.getInstrumentation()
                as PatrolJUnitRunner
        instrumentation.runDartTest(/* dartTestName supplied by ctor */
            (this.javaClass.getDeclaredField("dartTestName$0")
                .also { it.isAccessible = true }
                .get(this) as String))
    }
}
```

### 2.4 Shared test plumbing — `integration_test/_support/lupin_app.dart`

```dart
import 'dart:async';
import 'dart:convert';
import 'dart:io';

import 'package:flutter/material.dart';
import 'package:patrol/patrol.dart';

import 'package:lupin/main.dart' as lupin;

/// Pump the production widget tree without re-initialising bindings.
Future<void> bootLupin(PatrolIntegrationTester $) async {
  await $.pumpWidgetAndSettle(const lupin.LupinApp());
}

/// Run an arbitrary command on the device-under-test using its shell.
/// Patrol tests execute inside the AUT/instrumentation process pair on the
/// device, so `Process.run('sh', …)` is a valid escape hatch into the
/// Android shell user (uid=shell) which holds READ_LOGS by default.
Future<String> deviceShell(String cmd) async {
  final r = await Process.run('sh', ['-c', cmd]);
  if (r.exitCode != 0) {
    throw StateError('shell failed (${r.exitCode}): ${r.stderr}');
  }
  return (r.stdout as String);
}

/// Ring-buffer logcat read for a tag, last [tail] lines.
Future<List<String>> logcatTail(String tag, {int tail = 200}) async {
  final out = await deviceShell('logcat -d -t $tail -s $tag');
  return const LineSplitter().convert(out);
}

/// Hit the Lupin backend prerequisite probe and return the parsed JSON map.
Future<Map<String, dynamic>> voicePersonaStatus({
  required String host,
  required String mockJobsEmail,
}) async {
  final token = 'mock_token_email_$mockJobsEmail';
  final cmd =
      'curl -s -m 5 http://$host:7999/api/cosa-voice/voice-persona/status '
      '-H "Authorization: Bearer $token"';
  final body = await deviceShell(cmd);
  return jsonDecode(body) as Map<String, dynamic>;
}
```

### 2.5 vp1 — Inbox sender-tile badge — `integration_test/vp1_inbox_badge_test.dart`

The acceptance criterion has three claims: (i) allocated senders render a coloured badge with an emoji glyph in the leading slot, (ii) unallocated senders render a legacy `CircleAvatar` first-letter, (iii) long-press on a badge surfaces a `Tooltip` whose `message` equals the persona `displayName`. We assume each tile is keyed by `Key('inbox_tile_<senderId>')` and the badge widget by `Key('persona_badge_<senderId>')` — adjust if your Lupin tree uses different keys.

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:patrol/patrol.dart';

import '_support/lupin_app.dart';

void main() {
  patrolTest(
    'vp1 inbox badge: allocated → coloured badge+emoji; unallocated → CircleAvatar; long-press tooltip',
    ($) async {
      final status = await voicePersonaStatus(
        host: kLupinHost, mockJobsEmail: kMockJobsEmail,
      );
      final allocations = (status['allocations'] as Map).cast<String, dynamic>();
      expect(allocations.isNotEmpty, true,
          reason: 'pre-req: backend must report at least one allocation');

      await bootLupin($);
      await $(#inbox_screen).waitUntilVisible();

      // Pick first allocated sender and first unallocated sender.
      final allocatedId = allocations.entries
          .firstWhere((e) => (e.value as Map)['persona'] != null).key;
      final allocatedDisplay =
          ((allocations[allocatedId] as Map)['displayName'] ?? allocatedId).toString();
      final unallocatedId = allocations.entries
          .firstWhere((e) => (e.value as Map)['persona'] == null,
              orElse: () => MapEntry('__none__', null)).key;

      // (i) allocated sender → badge widget present, CircleAvatar absent in leading slot.
      final allocTile = $(Key('inbox_tile_$allocatedId'));
      await allocTile.waitUntilVisible();
      expect(allocTile.$(Key('persona_badge_$allocatedId')), findsOneWidget);
      expect(allocTile.$(CircleAvatar), findsNothing);

      // (ii) unallocated sender (only if one exists) → CircleAvatar visible.
      if (unallocatedId != '__none__') {
        final unTile = $(Key('inbox_tile_$unallocatedId'));
        await unTile.waitUntilVisible();
        expect(unTile.$(CircleAvatar), findsOneWidget);
        expect(unTile.$(Key('persona_badge_$unallocatedId')), findsNothing);
      }

      // (iii) long-press → Tooltip with displayName.
      await $(Key('persona_badge_$allocatedId'))
          .longPress(settlePolicy: SettlePolicy.trySettle);
      expect($(Tooltip).containing(allocatedDisplay), findsOneWidget);
    },
    nativeAutomatorConfig: const NativeAutomatorConfig(
      packageName: 'com.google.lupin.app',
    ),
  );
}
```

### 2.6 vp2 — ConversationScreen header badge — `integration_test/vp2_appbar_badge_test.dart`

Asserts (i) the AppBar badge is exactly 28 logical pixels, (ii) `senderId` text appears next to the badge in the same `Row`, (iii) the badge colour for sender X on the conversation header matches the inbox tile badge colour for the same X, (iv) reassigning the persona mid-session updates the AppBar badge colour. The test uses a backend admin endpoint (`POST /voice-persona/reassign`) — adapt to your real reassignment surface.

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:patrol/patrol.dart';
import 'dart:io';

import '_support/lupin_app.dart';

Color _decoColor(BuildContext _, Element el) {
  final w = el.widget;
  if (w is DecoratedBox) {
    final d = w.decoration;
    if (d is BoxDecoration && d.color != null) return d.color!;
  }
  if (w is Container && w.decoration is BoxDecoration) {
    return (w.decoration as BoxDecoration).color ?? const Color(0x00000000);
  }
  return const Color(0x00000000);
}

void main() {
  patrolTest(
    'vp2 AppBar badge: 28px, senderId text, color matches inbox, reassignment updates AppBar',
    ($) async {
      final status = await voicePersonaStatus(
        host: kLupinHost, mockJobsEmail: kMockJobsEmail,
      );
      final allocations = (status['allocations'] as Map).cast<String, dynamic>();
      final senderId = allocations.entries
          .firstWhere((e) => (e.value as Map)['persona'] != null).key;

      await bootLupin($);
      await $(#inbox_screen).waitUntilVisible();

      // Capture inbox-tile badge color first.
      final inboxBadgeFinder = $(Key('persona_badge_$senderId'));
      await inboxBadgeFinder.waitUntilVisible();
      final inboxBadgeEl = inboxBadgeFinder.evaluate().first;
      final inboxColor = _decoColor(inboxBadgeEl as BuildContext, inboxBadgeEl);

      // Drill into the conversation.
      await $(Key('inbox_tile_$senderId')).tap();
      await $(#conversation_screen).waitUntilVisible();

      // (i) 28px size assertion.
      final appbarBadge = $(Key('appbar_persona_badge_$senderId'));
      await appbarBadge.waitUntilVisible();
      final size = $.tester.getSize(appbarBadge.finder);
      expect(size.width.round(), 28);
      expect(size.height.round(), 28);

      // (ii) senderId text in same Row.
      final headerRow = $(Key('appbar_header_row'));
      expect(headerRow.containing(Text).$(senderId), findsOneWidget);

      // (iii) AppBar colour == inbox colour.
      final appbarBadgeEl = appbarBadge.evaluate().first;
      final appbarColor =
          _decoColor(appbarBadgeEl as BuildContext, appbarBadgeEl);
      expect(appbarColor.value, inboxColor.value,
          reason: 'AppBar badge color must match inbox badge color');

      // (iv) reassign via backend, then assert color changes.
      final reassignCmd = 'curl -s -X POST '
          'http://$kLupinHost:7999/api/cosa-voice/voice-persona/reassign '
          '-H "Authorization: Bearer mock_token_email_$kMockJobsEmail" '
          '-H "Content-Type: application/json" '
          "-d '{\"sender_id\":\"$senderId\",\"persona\":\"Bella\"}'";
      await deviceShell(reassignCmd);

      // Allow the WS push to mutate state, then re-evaluate.
      await Future<void>.delayed(const Duration(seconds: 2));
      await $.pump();
      final appbarBadgeEl2 = $(Key('appbar_persona_badge_$senderId'))
          .evaluate().first;
      final appbarColor2 =
          _decoColor(appbarBadgeEl2 as BuildContext, appbarBadgeEl2);
      expect(appbarColor2.value, isNot(appbarColor.value),
          reason: 'AppBar badge colour must update after reassignment');

      // Logcat sanity: a reassignment envelope should have flowed.
      final lines = await logcatTail('lupin_ws', tail: 400);
      expect(
        lines.any((l) => l.contains('persona_reassigned')
                       && l.contains(senderId)),
        true,
        reason: 'Reassignment WS event missing from logcat',
      );
    },
    nativeAutomatorConfig: const NativeAutomatorConfig(
      packageName: 'com.google.lupin.app',
    ),
  );
}
```

### 2.8 vp4 — Borrowed-persona dashed border — `integration_test/vp4_borrowed_dashed_test.dart`

This gate is conditional: if no sender currently has `borrowed=true`, the test is skipped (logged, not failed). The dashed-border overlay is a `CustomPaint` whose `Key('borrowed_dashed_overlay_<senderId>')` we expect to find layered on top of the badge.

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:patrol/patrol.dart';

import '_support/lupin_app.dart';

void main() {
  patrolTest(
    'vp4 borrowed=true → dashed circular border overlay visible on badge',
    ($) async {
      final status = await voicePersonaStatus(
        host: kLupinHost, mockJobsEmail: kMockJobsEmail,
      );
      final allocations = (status['allocations'] as Map).cast<String, dynamic>();
      final borrowedEntry = allocations.entries.firstWhere(
        (e) => (e.value as Map)['borrowed'] == true,
        orElse: () => const MapEntry('__none__', null),
      );

      if (borrowedEntry.key == '__none__') {
        // Conditional skip: print and return cleanly; CI parses this string.
        // ignore: avoid_print
        print('vp4: SKIPPED — no sender currently has borrowed=true');
        return;
      }

      final senderId = borrowedEntry.key;
      await bootLupin($);
      await $(#inbox_screen).waitUntilVisible();
      await $(Key('inbox_tile_$senderId')).waitUntilVisible();

      // Both the underlying badge and the dashed overlay must exist.
      expect($(Key('persona_badge_$senderId')), findsOneWidget);
      expect($(Key('borrowed_dashed_overlay_$senderId')), findsOneWidget,
          reason: 'dashed border CustomPaint missing for borrowed sender');

      // The overlay must be a CustomPaint sized to the badge.
      final overlay = $(Key('borrowed_dashed_overlay_$senderId'));
      final overlaySize = $.tester.getSize(overlay.finder);
      final badgeSize = $.tester.getSize(
          $(Key('persona_badge_$senderId')).finder);
      expect((overlaySize.width - badgeSize.width).abs() < 2, true);
      expect((overlaySize.height - badgeSize.height).abs() < 2, true);
    },
    nativeAutomatorConfig: const NativeAutomatorConfig(
      packageName: 'com.google.lupin.app',
    ),
  );
}
```

### 2.9 vp6-infra — voice_id correlation across rapid FIFO — `integration_test/vp6_voice_id_logcat_test.dart`

Infrastructure-only: confirm the backend returns a non-Sam persona, and that the WS envelopes for `s5` and `s5b` (fired in rapid succession) carry the *same* `voice_id`, and that this `voice_id` is one of the six canonical (non-Sam) values.

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:patrol/patrol.dart';
import 'package:flutter/material.dart';

import '_support/lupin_app.dart';

void main() {
  patrolTest(
    'vp6-infra non-Sam persona; FIFO s5+s5b envelopes carry identical canonical voice_id',
    ($) async {
      // (1) backend status: persona must NOT be Sam.
      final status = await voicePersonaStatus(
        host: kLupinHost, mockJobsEmail: kMockJobsEmail,
      );
      final personaName = (status['active_persona'] ?? '').toString();
      expect(personaName.isNotEmpty, true,
          reason: '/voice-persona/status must report an active persona');
      expect(personaName, isNot(equals('Sam')),
          reason: 'persona must not be Sam fallback');

      final expectedId = kPersonaVoiceIds[personaName];
      expect(expectedId, isNotNull, reason: 'unknown persona $personaName');
      expect(expectedId, isNot(equals(kSamFallbackId)));

      // (2) clear logcat then fire s5 and s5b in rapid FIFO.
      await deviceShell('logcat -c');
      await bootLupin($);
      await $(#dev_panel_open).tap();
      await $(Key('fire_scenario_s5')).tap();
      await $(Key('fire_scenario_s5b')).tap();

      // Allow WS envelopes to flush.
      await Future<void>.delayed(const Duration(seconds: 6));

      // (3) parse logcat for envelopes.
      final lines = await logcatTail('lupin_ws', tail: 500);
      final voiceIdRe = RegExp(r'voice_id="([A-Za-z0-9]{20})"');
      final scenarioRe = RegExp(r'scenario="(s5b?)"');
      final pairs = <String, String>{}; // scenario -> voice_id
      for (final l in lines) {
        final s = scenarioRe.firstMatch(l)?.group(1);
        final v = voiceIdRe.firstMatch(l)?.group(1);
        if (s != null && v != null) pairs[s] = v;
      }

      expect(pairs['s5'], isNotNull, reason: 's5 envelope absent from logcat');
      expect(pairs['s5b'], isNotNull, reason: 's5b envelope absent from logcat');
      expect(pairs['s5'], equals(expectedId),
          reason: 's5 voice_id must equal canonical id for $personaName');
      expect(pairs['s5b'], equals(pairs['s5']),
          reason: 's5b must reuse the same voice_id as s5');
      expect(pairs['s5'], isNot(equals(kSamFallbackId)));
    },
    nativeAutomatorConfig: const NativeAutomatorConfig(
      packageName: 'com.google.lupin.app',
    ),
  );
}
```

### 2.10 vp7-infra — quota fallback engine path + 5-minute window — `integration_test/vp7_quota_fallback_logcat_test.dart`

The test runs only when the binary is built with `--dart-define LUPIN_DEV_SIMULATE_TTS_ERROR=true` (this is how Lupin forces the simulated quota-exhaustion path). Inside, we assert: (a) firing `s8` produces a `flutter_tts` engine log line and *no* `elevenlabs.stream` line; (b) a follow-up fire ≤5 min later still routes to `flutter_tts`; (c) a fire >5 min after the first error returns to ElevenLabs.

```dart
import 'package:flutter_test/flutter_test.dart';
import 'package:patrol/patrol.dart';
import 'package:flutter/material.dart';

import '_support/lupin_app.dart';

const _simulateError =
    bool.fromEnvironment('LUPIN_DEV_SIMULATE_TTS_ERROR', defaultValue: false);

void main() {
  patrolTest(
    'vp7-infra quota fallback: flutter_tts engine path; same path within 5min; ElevenLabs after 5min',
    ($) async {
      if (!_simulateError) {
        // ignore: avoid_print
        print('vp7-infra: SKIPPED — build without LUPIN_DEV_SIMULATE_TTS_ERROR');
        return;
      }

      await deviceShell('logcat -c');
      await bootLupin($);
      await $(#dev_panel_open).tap();

      // === First fire: must route to flutter_tts ===
      await $(Key('fire_scenario_s8')).tap();
      await Future<void>.delayed(const Duration(seconds: 4));
      var lines = await logcatTail('lupin_tts', tail: 400);
      final firstFlutterTts = lines.firstWhere(
        (l) => l.contains('engine=flutter_tts'),
        orElse: () => '',
      );
      expect(firstFlutterTts.isNotEmpty, true,
          reason: 'expected engine=flutter_tts on first fire');
      expect(lines.any((l) => l.contains('engine=elevenlabs')), false,
          reason: 'must NOT route to ElevenLabs while simulating error');

      // Capture epoch-ms of first error from logcat threadtime.
      final tsRe = RegExp(r'^(\d{2}-\d{2} \d{2}:\d{2}:\d{2}\.\d{3})');
      final firstTs = tsRe.firstMatch(firstFlutterTts)?.group(1);
      expect(firstTs, isNotNull);

      // === Second fire within 5 min: must stay on flutter_tts ===
      await $(Key('fire_scenario_s8')).tap();
      await Future<void>.delayed(const Duration(seconds: 4));
      lines = await logcatTail('lupin_tts', tail: 600);
      final fttsCount =
          lines.where((l) => l.contains('engine=flutter_tts')).length;
      expect(fttsCount >= 2, true,
          reason: 'second fire (within 5min) must also use flutter_tts');
      expect(lines.any((l) => l.contains('engine=elevenlabs')), false,
          reason: 'no ElevenLabs path expected within 5min window');

      // === After 5 min: must return to ElevenLabs ===
      // We do not actually sleep five minutes inside the test. Instead, we
      // poke the dev-only window-reset endpoint that simulates clock advance.
      await deviceShell(
        'curl -s -X POST '
        'http://$kLupinHost:7999/api/cosa-voice/_dev/advance-quota-clock '
        '-H "Authorization: Bearer mock_token_email_$kMockJobsEmail" '
        '-H "Content-Type: application/json" '
        "-d '{\"seconds\":301}'",
      );
      await deviceShell('logcat -c');
      await $(Key('fire_scenario_s8')).tap();
      await Future<void>.delayed(const Duration(seconds: 6));
      lines = await logcatTail('lupin_tts', tail: 200);
      expect(lines.any((l) => l.contains('engine=elevenlabs')), true,
          reason: 'after 5min window must return to ElevenLabs');
    },
    nativeAutomatorConfig: const NativeAutomatorConfig(
      packageName: 'com.google.lupin.app',
    ),
  );
}
```

## Deliverable 3 — Human-Perception CLI — `tools/qa/human_signoff.py`

Single-file, standard-library Python 3.10+ (no Flask, no FastAPI, no third-party dependencies). It walks the operator through `vp5`, `vp6-perceptual`, and `vp7-audible`, captures thumbs ± free text, queries `adb` for device metadata, queries `git` for the APK commit, and emits a Markdown sign-off file matching the existing runbook formatting convention (H2 per gate, `**Acceptance**`, `**Result**`, `**Observation**`).

```python
#!/usr/bin/env python3
"""Lupin voice-persona — human-perception sign-off CLI.

Walks an operator through the three residual gates that no Patrol assertion
can mechanise (vp5 light/dark contrast, vp6-perceptual TTS timbre, vp7-audible
robotic-vs-natural engine identity) and emits a Markdown sign-off artifact.

Usage:
    python tools/qa/human_signoff.py \\
        --output docs/runbooks/voice_persona/signoff_YYYYMMDD_HHMM.md
"""
from __future__ import annotations

import argparse
import datetime as _dt
import getpass
import os
import shutil
import subprocess
import sys
from dataclasses import dataclass, field
from pathlib import Path
from typing import Optional

# ---------------------------------------------------------------------------
# Persona reference table (verbatim from runbook, with one-line timbre cues
# drawn from the public ElevenLabs premade voice descriptions).
# ---------------------------------------------------------------------------
PERSONAS: dict[str, dict[str, str]] = {
    "Adam":    {"voice_id": "pNInz6obpgDQGcFmaJgB",
                "timbre": "deep middle-aged American male, narrator weight"},
    "Bella":   {"voice_id": "EXAVITQu4vr4xnSDxMaL",
                "timbre": "soft young American female, breathy mid-range"},
    "Domi":    {"voice_id": "AZnzlk1XvdvUeBnXmlld",
                "timbre": "strong young American female, assertive bright"},
    "Antoni":  {"voice_id": "ErXwobaYiN019PkySvjV",
                "timbre": "well-rounded young American male, friendly tenor"},
    "Rachel":  {"voice_id": "21m00Tcm4TlvDq8ikWAM",
                "timbre": "calm young American female, neutral conversational"},
    "Arnold":  {"voice_id": "VR6AewLTigWG4xSOukaG",
                "timbre": "crisp middle-aged American male, narrator authority"},
    "Sam":     {"voice_id": "yoZ06aMxZJJ28mfd3POQ",
                "timbre": "raspy mid-range male — the FALLBACK; should NOT play"},
}

# ---------------------------------------------------------------------------
# Data model
# ---------------------------------------------------------------------------
@dataclass
class GateResult:
    gate_id: str
    title: str
    acceptance: str
    thumb: str       # "UP" or "DOWN"
    observation: str
    timestamp: str   # ISO-8601 UTC

@dataclass
class SignOff:
    operator: str
    device_model: str
    android_release: str
    apk_commit: str
    started_at: str
    finished_at: str = ""
    results: list[GateResult] = field(default_factory=list)

# ---------------------------------------------------------------------------
# Shell helpers
# ---------------------------------------------------------------------------
def _run(cmd: list[str], default: str = "unknown") -> str:
    try:
        out = subprocess.run(cmd, capture_output=True, text=True, timeout=10,
                             check=False)
        return (out.stdout or "").strip() or default
    except (FileNotFoundError, subprocess.TimeoutExpired):
        return default

def adb_getprop(prop: str) -> str:
    if not shutil.which("adb"):
        return "unknown (adb missing)"
    return _run(["adb", "shell", "getprop", prop])

def git_short_sha() -> str:
    if not shutil.which("git"):
        return "unknown (git missing)"
    return _run(["git", "rev-parse", "--short", "HEAD"])

def now_iso() -> str:
    return _dt.datetime.now(_dt.timezone.utc).isoformat(timespec="seconds")

# ---------------------------------------------------------------------------
# Interactive prompts
# ---------------------------------------------------------------------------
def banner(text: str) -> None:
    print("\n" + "=" * 72)
    print(text)
    print("=" * 72)

def yesno(prompt: str) -> str:
    while True:
        ans = input(f"{prompt} [y/n] ").strip().lower()
        if ans in ("y", "yes"):  return "UP"
        if ans in ("n", "no"):   return "DOWN"
        print("  please answer y or n")

def free_text(prompt: str) -> str:
    print(prompt)
    return input("> ").strip()

def ask_gate(gate_id: str, title: str, acceptance: str,
             instruction: str) -> GateResult:
    banner(f"{gate_id} — {title}")
    print(f"Acceptance: {acceptance}\n")
    print(f"Operator action:\n  {instruction}\n")
    input("Press ENTER when you have completed the action above…")
    thumb = yesno("Did the gate pass?")
    note = free_text("One-line observation (or ENTER for none):") or "(none)"
    return GateResult(gate_id=gate_id, title=title, acceptance=acceptance,
                      thumb=thumb, observation=note, timestamp=now_iso())

# ---------------------------------------------------------------------------
# Gate definitions
# ---------------------------------------------------------------------------
def gate_vp5() -> GateResult:
    return ask_gate(
        "vp5", "Light + dark mode contrast",
        "Badge text and emoji glyph must remain legible against the badge "
        "fill in BOTH light and dark themes; no AA-failure on body copy.",
        "Toggle the system theme (Settings → Display → Dark theme), inspect "
        "the inbox tile badges and the AppBar badge in BOTH modes. Confirm "
        "all foregrounds are clearly readable.",
    )

def gate_vp6_perceptual() -> GateResult:
    persona_lines = "\n".join(
        f"    • {n:<7} ({d['voice_id']}) — {d['timbre']}"
        for n, d in PERSONAS.items()
    )
    return ask_gate(
        "vp6-perceptual", "TTS persona-voice timbre",
        "Re-fire scenarios s2, s3, s5, s5b. The audible voice must match the "
        "timbre of the allocated persona — NOT the Sam fallback.",
        "Re-fire s2, s3, s5, s5b from the dev panel. Listen carefully and "
        "match what you hear to one of the seven canonical timbres:\n"
        f"{persona_lines}\n"
        "  Confirm the playback matches the persona returned by the backend "
        "/voice-persona/status endpoint, and that you do NOT hear the raspy "
        "Sam fallback.",
    )

def gate_vp7_audible() -> GateResult:
    return ask_gate(
        "vp7-audible", "Quota fallback engine character",
        "Under simulated quota error, s8 must play with the noticeably more "
        "robotic / stilted prosody of on-device flutter_tts, not the smooth "
        "ElevenLabs character; subsequent fires within 5 minutes stay "
        "robotic; after 5 minutes the smooth ElevenLabs character returns.",
        "With LUPIN_DEV_SIMULATE_TTS_ERROR=true, fire s8 once. Listen: does "
        "it sound robotic / clipped / synthetic compared to s2? Fire it "
        "again within 5 min — still robotic? Wait or advance the quota "
        "clock past 5 min, fire s8 a third time — does it sound smooth "
        "again (ElevenLabs)?",
    )

# ---------------------------------------------------------------------------
# Markdown emitter
# ---------------------------------------------------------------------------
def render_markdown(s: SignOff) -> str:
    icon = lambda t: "✅" if t == "UP" else "❌"
    lines = [
        "# Lupin Voice-Persona — Human-Perception Sign-Off",
        "",
        f"- **Operator**:        `{s.operator}`",
        f"- **Device model**:    `{s.device_model}`",
        f"- **Android release**: `{s.android_release}`",
        f"- **APK commit**:      `{s.apk_commit}`",
        f"- **Started (UTC)**:   `{s.started_at}`",
        f"- **Finished (UTC)**:  `{s.finished_at}`",
        "",
        "## Persona reference table",
        "",
        "| Persona | voice_id | Timbre cue |",
        "|---------|----------|------------|",
    ]
    for n, d in PERSONAS.items():
        lines.append(f"| {n} | `{d['voice_id']}` | {d['timbre']} |")
    lines.append("")

    for r in s.results:
        lines += [
            f"## {r.gate_id} — {r.title}",
            "",
            f"**Acceptance**: {r.acceptance}",
            "",
            f"**Result**: {icon(r.thumb)} `{r.thumb}`  (at `{r.timestamp}`)",
            "",
            f"**Observation**: {r.observation}",
            "",
        ]

    overall = "PASS" if all(r.thumb == "UP" for r in s.results) else "FAIL"
    lines += [
        "## Overall",
        "",
        f"**Verdict**: `{overall}` "
        f"({sum(1 for r in s.results if r.thumb == 'UP')}/{len(s.results)} gates UP)",
        "",
    ]
    return "\n".join(lines)

# ---------------------------------------------------------------------------
# Entry point
# ---------------------------------------------------------------------------
def main(argv: Optional[list[str]] = None) -> int:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument(
        "--output", type=Path, required=True,
        help="Path to write the Markdown sign-off file",
    )
    p.add_argument(
        "--operator", default=getpass.getuser(),
        help="Operator name (default: $USER)",
    )
    args = p.parse_args(argv)

    s = SignOff(
        operator=args.operator,
        device_model=adb_getprop("ro.product.model"),
        android_release=adb_getprop("ro.build.version.release"),
        apk_commit=git_short_sha(),
        started_at=now_iso(),
    )

    banner("Lupin voice-persona — human-perception sign-off")
    print("This walk-through captures vp5, vp6-perceptual, vp7-audible.\n"
          "It is the residual human gate after Patrol has run.\n")
    print(f"  device   : {s.device_model}")
    print(f"  android  : {s.android_release}")
    print(f"  commit   : {s.apk_commit}")
    print(f"  operator : {s.operator}\n")
    if input("Proceed? [y/n] ").strip().lower() not in ("y", "yes"):
        print("aborted.")
        return 2

    s.results.append(gate_vp5())
    s.results.append(gate_vp6_perceptual())
    s.results.append(gate_vp7_audible())
    s.finished_at = now_iso()

    args.output.parent.mkdir(parents=True, exist_ok=True)
    args.output.write_text(render_markdown(s), encoding="utf-8")

    banner(f"Sign-off written → {args.output}")
    overall = "PASS" if all(r.thumb == "UP" for r in s.results) else "FAIL"
    print(f"Overall verdict: {overall}")
    return 0 if overall == "PASS" else 1

if __name__ == "__main__":
    sys.exit(main())
```

## Integration notes — how the three deliverables compose

The three artifacts collapse into a single milestone close-out by design.

**1. Authoring stage** — The Claude Code prompt (Deliverable 1) is run once per runbook revision. It reads `docs/runbooks/voice_persona_validation.md` and emits three child files: `automated_patrol.md` (operational reference for Deliverable 2), `human_perception.md` (operational reference for Deliverable 3), and `metadata_signoff.md` (documents the Python CLI's invocation contract). The split is deterministic and re-runnable: if the source runbook changes, re-running the prompt re-derives the three child files without manual reconciliation.

**2. Execution stage** — On every QA pass, three artefacts are produced in order. First, the automated Patrol suite (Deliverable 2) is executed via `patrol test`; on Android, Patrol's `PatrolJUnitRunner` writes `build/app/outputs/androidTest-results/connected/test-result.pb` and an HTML report at `build/app/reports/androidTests/connected/index.html`. These cover `vp1`–`vp4` exhaustively and `vp6`/`vp7` at the *infrastructure* layer (logcat envelope `voice_id`, engine path, 5-minute window). Second, the human-perception script (Deliverable 3) is executed by a designated operator with the device tethered. It captures `vp5`, `vp6-perceptual`, and `vp7-audible`, writes a timestamped Markdown sign-off to `docs/runbooks/voice_persona/signoff_<UTC>.md`, and exits with a status code that reflects the aggregate human verdict.

**3. Close-out stage** — A milestone is considered closed when (a) the Patrol HTML report shows zero failed/zero skipped-without-justification gates, and (b) the Python CLI's Markdown sign-off shows `Verdict: PASS` for all three human gates. The Markdown sign-off file references the APK commit (via `git rev-parse --short HEAD`) and the device fingerprint (`ro.product.model` + `ro.build.version.release`), making the human stamp cryptographically and contextually traceable to the same artefact that Patrol exercised. Together, the Patrol report and the Markdown sign-off constitute the auditable record that voice-persona allocation, badge rendering, voice-id correlation, and quota-fallback engine handling are all simultaneously correct in widget-tree, transport, and human-perceptual senses — which is exactly the partition that the single-canvas Flutter rendering model forces us to draw.

The architectural premise is worth restating in closing. Because Flutter rasterises into a single native view, the only mechanical introspection path on Android is the one Patrol opens via `integration_test` + `PatrolJUnitRunner`. Anything that cannot be expressed as a `Finder` against the Dart element tree, a logcat regex, or an HTTP probe of the Lupin backend has been intentionally pushed out of Deliverable 2 and into Deliverable 3 — not as a deficit, but as the correct boundary. The Claude Code prompt formalises this boundary so that future runbook authors cannot accidentally write a "gate" that straddles it.
