## What changed

The two doors `_retired_doors.py` tombstones with 410 (REMOVE BY 2026-12-31) no longer have a caller in this repo.
`/api/v2/ask` is **synchronous** where `/api/push` was queue-and-poll, so the shape change was carried through
the repository → BLoC → UI, not just the URL string.

| File | Change |
|---|---|
| `lib/features/queue/data/queue_models.dart` | `PushJobRequest` → **`AskRequest`** (`question`, `websocket_id?`, `speak=true`, `interactive=true`); NEW **`AskResponse`** (the §8 result dict: `path/status/route_reason/answer/…/trace_id/error` + `isDone`/`needsInput`/`isFailed`/`summary`); `RetryJobResponse` deleted (dead door) |
| `lib/features/queue/data/queue_repository.dart` | `push()` → **`ask()`** → `POST /api/v2/ask`; **`retryJob( jobId:, questionText:, websocketId: )`** re-asks via `/api/v2/ask` — the old handler pulled `question_text` off the stored row server-side, the client now supplies it (`JobSummary.questionText` / `JobHistoryEntry.questionText`) |
| `lib/features/queue/domain/queue_event.dart` | `QueueSubmitJob( AskRequest )`; `QueueRetryJob` gains `questionText` (required), `websocketId` optional |
| `lib/features/queue/domain/queue_state.dart` | NEW **`QueueAnswered( AskResponse )`** — `QueueSubmitted( PushJobResponse )` stays for `/api/push-agentic` |
| `lib/features/queue/domain/queue_bloc.dart` | submit → `repo.ask` → `QueueAnswered`; retry → `QueueActionComplete( "Retried (<status>): <summary>" )` |
| `lib/features/queue/presentation/submit_job_sheet.dart` | builds `AskRequest`; sheet pops on `QueueAnswered` too |
| `lib/features/queue/presentation/queue_dashboard_screen.dart` | snackbar shows the answer / first clarifying question / failure (red) — no "Job queued" for asks |

**Untouched on purpose**: the eleven submit-shaped doors (nine in `agentic_repository.dart`, `/api/push-agentic`,
`/api/jobs/{id}/resume-from-checkpoint`) — wave 2, after `/api/v2/submit` exists; and `/api/deep-research/report`
(`agentic_repository.dart:42`) — a read, not a dying door.
