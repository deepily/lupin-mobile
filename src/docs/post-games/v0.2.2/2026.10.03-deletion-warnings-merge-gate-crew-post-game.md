## 6. Lessons for the failure-mode catalog

- **Gate green on its own range.** Trigger: a gate's author shows it passing on the commits that add it. Symptom: the gate passes bad commits (ten ways here). Guard: R6.
- **Hollow refusal test.** Trigger: a test checks an exit code that several causes share, or was never seen red. Symptom: the test stays green when the rule is removed. Guard: R7.
- **Instance fix.** Trigger: a review finding is fixed exactly as reported. Symptom: the next review finds the same hole one step along. Guard: R10.
- **Deletion checked by imports alone.** Trigger: "nothing imports it" is taken as "nothing names it". Symptom: emptied directories with live config; a test table naming a dead file. Guard: R8.
- **Size standing in for completeness.** Trigger: a check accepts a hand-over by byte count. Symptom: a complete short memento is flagged and a long empty one would pass. Guard: none yet (open thread 2).
