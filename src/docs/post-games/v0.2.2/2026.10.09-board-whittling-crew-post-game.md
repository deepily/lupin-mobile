## 6. Lessons for the failure-mode catalog

- **Half the blast radius.** Trigger: a merge changes a file that a second repo's tests read. Symptom: the one test you were told about passes, another goes red in someone else's tier. Guard: R12, a search by path, because the list in your head is the list of tests someone mentioned.
- **A lesson filed in a handover is not installed.** Trigger: a self-correction recorded as "do not repeat this". Symptom: the same act two hours later by the seat that wrote the note. Guard: a check that runs without being remembered; until one exists, say plainly that there is none.
- **Owed by ownership only.** Trigger: building an owed list from rows you own. Symptom: a peer's row that waits on you disappears at a clear. Guard: R14.
